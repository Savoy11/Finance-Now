## Problems that are not prompt problems

The T6 brief asks for these separately: problems in tools, wiring or data, which no prompt change
would fix. All were fixed in the pull request that carries this record, except the last two.

1. **Answer text broken across lines** wherever an agent quoted the web. The runner now joins the
   text blocks as they stand (`anthropicAnswerText`, `lib/agents/runner.ts`).
2. **Cut-off answers looked whole.** An answer stopped at its length limit now ends with a notice
   saying so (`CUT_OFF_NOTICE`), on the Anthropic and the OpenAI-compatible paths. The research
   route's limit is 8,192 tokens, up from 4,096; only the tokens an answer uses are billed.
3. **The network-fee data named no fee source.** Each live fee now carries `provider`
   (`mempool.space`, `publicnode eth_gasPrice`), and the response's note says the credit is for the
   prices. The MCP server shows it too.
4. **Wikipedia's text reached the agents unnamed.** `get_stock_profile` now returns the background
   with `source: 'Wikipedia'`, the article link and the licence, and its description says to
   credit it. The stock page already linked it.
5. **The outlier screen did not date its figures.** On the hand-kept list its note now says the
   P/E, yield and beta are reference values compiled 2026-07-07, how many days old, and that the
   whole-market list needs a paid FMP plan (`catalogUniverseNote`, `equityCatalog.ts`).
6. **The yield-curve tool gave spreads for today only.** The month-ago and year-start curves now
   come with their own spreads (`spreadsOf`, `lib/server/treasuryCurve.ts`), through both curve
   routes and the agent tool, and the tool's description says to compare them.
7. **Macro prices are unserved** (the audit's known gap since 2026-09-09). Not fixed; a paid FMP
   plan or a symbol-mapping fix, deferred under D21.
8. **The staking catalog lists a trading pool as staking** (Uniswap ETH/USDC, 3.5%). Not changed
   here: the owner chose to have it, and the Kraken line, put on the Staking Facts Check page for a
   decision there (D136).

The evaluation script had faults of its own, also fixed: "Tools called" printed `[object Object]`;
the Pump Report routes' times were the time to the first words, not the whole answer (3.3 s for a
16,685-character report with 8 searches); and the Macro Screener's task is now the day's biggest
moves.
