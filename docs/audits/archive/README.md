# docs/audits/archive/

Audit artifacts kept for the record rather than for use.

**Archiving here means the file stays and is labelled — it never means deletion.** That is
the same rule CLAUDE.md sets for branches ("retiring a branch means tagging it, not
deleting it") and the same standing rule the owner set on 2026-09-12: *"I will not enable
or authorize any auto delete functions for any project files related to the build."*

A file belongs here when it is **superseded, duplicated, or was never completed**, and
keeping it in `docs/audits/` would make it look like live work. Every file here carries a
header stating what it is, why it was archived, and what replaced it — an archived document
with no explanation is just clutter with a date on it.

Nothing in this directory should be cited as a current finding.
